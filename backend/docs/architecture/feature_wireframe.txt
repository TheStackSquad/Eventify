┌─────────────────────────────────────────────────────────────────────────────┐
│ FEATURE 4: Subscription-Vendor Tier Synchronization                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ Status: ✅ IMPLEMENTED (Database Trigger)                                   │
│                                                                              │
│ Purpose: Keep vendors.subscription_tier in sync with active subscriptions   │
│                                                                              │
│ Trigger: trigger_sync_vendor_tier                                           │
│ ├─ Event: AFTER INSERT OR UPDATE ON subscriptions                          │
│ ├─ Function: sync_vendor_subscription_tier()                                │
│ └─ Scope: FOR EACH ROW                                                      │
│                                                                              │
│ Logic:                                                                       │
│ IF subscription becomes active:                                              │
│   UPDATE vendors                                                             │
│   SET subscription_tier = NEW.tier,                                          │
│       updated_at = NOW()                                                     │
│   WHERE id = NEW.vendor_id                                                   │
│                                                                              │
│ IF subscription expires/cancelled:                                           │
│   IF no other active subscription exists:                                    │
│     UPDATE vendors                                                           │
│     SET subscription_tier = 'free',                                          │
│         updated_at = NOW()                                                   │
│     WHERE id = NEW.vendor_id                                                 │
│                                                                              │
│ Affected Systems:                                                            │
│ ├─ Analytics tier gating (immediate effect)                                 │
│ ├─ Search result boosting (next query)                                      │
│ ├─ Leaderboard eligibility (next refresh)                                   │
│ └─ Feature access control (immediate)                                       │
│                                                                              │
│ Validation Query:                                                            │
│ SELECT                                                                       │
│   v.id,                                                                      │
│   v.subscription_tier as vendor_tier,                                        │
│   s.tier as subscription_tier,                                               │
│   s.status,                                                                  │
│   CASE WHEN v.subscription_tier = COALESCE(s.tier, 'free')                  │
│        THEN '✅ SYNCED' ELSE '❌ OUT OF SYNC' END                           │
│ FROM vendors v                                                               │
│ LEFT JOIN subscriptions s ON v.id = s.vendor_id                             │
│   AND s.status = 'active'                                                    │
│   AND (s.expires_at IS NULL OR s.expires_at > NOW())                        │
│                                                                              │
│ Performance:                                                                 │
│ ├─ Automatic (no application code)                                          │
│ ├─ ACID compliant                                                            │
│ └─ ~1-2ms per subscription change                                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ FEATURE 6: Review Count Auto-Increment                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ Status: ⚠️  NEEDS DATABASE TRIGGER                                          │
│                                                                              │
│ Current Issue:                                                               │
│ ├─ VendorRepository.IncrementField() supports "review_count"               │
│ └─ But it's never called when reviews are created                           │
│                                                                              │
│ Recommended Fix: Database Trigger                                            │
│                                                                              │
│ CREATE TRIGGER trigger_vendor_review_count                                   │
│   AFTER INSERT OR DELETE ON reviews                                          │
│   FOR EACH ROW                                                                │
│   EXECUTE FUNCTION increment_vendor_review_count()                           │
│                                                                              │
│ Function Logic:                                                              │
│ IF INSERT:                                                                   │
│   UPDATE vendors                                                             │
│   SET review_count = review_count + 1,                                       │
│       updated_at = NOW()                                                     │
│   WHERE id = NEW.vendor_id                                                   │
│                                                                              │
│ IF DELETE:                                                                   │
│   UPDATE vendors                                                             │
│   SET review_count = GREATEST(review_count - 1, 0),                          │
│       updated_at = NOW()                                                     │
│   WHERE id = OLD.vendor_id                                                   │
│                                                                              │
│ Why Trigger > Application Code:                                             │
│ ├─ Always consistent (can't forget to call)                                 │
│ ├─ Handles bulk operations                                                  │
│ ├─ Works even if review created via SQL                                     │
│ └─ No race conditions                                                        │
└─────────────────────────────────────────────────────────────────────────────┘
